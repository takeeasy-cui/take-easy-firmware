## 0. 背景与目标

用户早前在 `read-pico-reader`（上游 kiikoread 固件）上做过一版《伏魔记》移植实验（`伏魔记-固件集成/`），**未发布**。实测两个痛点：**① 人物走动刷新差（全屏整刷，墨水屏闪/慢）；② 高清素材效果差（SDF 7x 重绘发灰、AI 角色违和）**。本规划目标：把《伏魔记》以 **BBK 游戏分类**整合进 **take-easy 自研 GameCore 游戏内核**（当前 `gbbk.c` 仅骨架），攻克上述两个痛点，并恢复应用页「步步高游戏」入口。**不沿用那套实验稿的刷新/素材方案，不做兼容性考虑。**

## 3. 两个痛点对应方案

### 3.1 人物走动刷新 → 申报制差分 + 原版分屏语义（GameCore 的强项）

**实测病根（代码证据，2026-10-28 复核）**——用户反馈"人物移动有时会逐步刷新背景"，机理三连：

1. **每步整页刷**：`app_fmj.c` 的 `on_gesture`/`on_key` 一律 `return APP_REDRAW_PAGE` → 走一步整页刷新模式（含背景），墨水屏把背景 tile 也全部重驱动，肉眼即"背景跟着人物一步步刷"；
2. **render 全量重画**：每帧 `fmj_scene_draw` 把 9×6 全部可视 tile 重新贴屏（高清模式每块 112×112 的 `fmj_hd_blit`），解压+拷贝量大，刷新慢，GC16 驱动期间肉眼可见背景逐块变化；
3. **原版本就是分屏滚动**：镜头 `fmj_map_scr_x/y` **只由脚本设置**（`fmj_scene_load_map` 切场景 + 脚本指令 16 `screens` 跳镜头），**没有平滑跟随镜头**（`fmj_scene_walk` 里"玩家固定格"仅注释、未实现）。玩家走到屏边触发跳屏/切场景时全屏 tile 换内容 → 大面积一次性重刷。

**目标方案**：
- **屏内走动零背景刷**：地图 tile 渲染进 PSRAM 背景缓存一次；玩家/NPC 走动只申报「旧格 ∪ 新格」角色小矩形（DU/GL16 局部差分，含 4 帧行走动画 `k_walk_step 0,1,2,1` 的帧切换，都在角色框内）；对话框/战斗 UI 只申报对应区。背景像素 1 个不动。
- **跳屏/切场景一次 GC16**：原版 `screens` 分屏语义天然墨水屏友好——跳屏本来就是全屏变化，一次整屏 GC16 刷干净（"翻页"观感），**绝不做边缘逐步滚动**（每步全屏偏移重绘=用户现在看到的逐步刷背景，方案直接否决）。
- **走一步一帧动画**：原版即此节奏（step+1 & 3），差分矩形内换帧零负担。
- 完全走 GameCore 恒语义（`g->area` / `g->want_full`），插件层不碰整刷。

**镜头策略（决策点 ①-5）**：实验稿玩家可走到 9×6 窗口边缘（walk 通行按整图判定、无镜头跟随、也未把窗边挡住）。三选一：
- **A. 原版事件跳屏**（推荐）：照原版 `screens` 语义，地图按 9×6 屏设计、出入口在屏边由脚本触发跳屏——屏内零背景刷、跳屏一次整刷，最贴原版；
- **B. 出界自动跳屏**：玩家碰窗口边缘时镜头一次跳"一屏减一格"（玩家回窗口中部），一次 GC16——兼容走出窗口的情形；
- **C. 边缘逐步滚动**：每过中线带镜头平移 1 格 → 每步大面积刷，即用户实测痛点，**否决**。

### 3.2 素材（弃高清库，回归原版点阵，追求清晰不"糊"）
- **现状痛点**：FMJHD.BIN 是 SDF 7x 重绘（边缘 16 级灰→墨水屏发灰发糊）+ AI 角色（风格违和）。
- **目标方案**：**弃 FMJHD.BIN 整库**，走 DAT.LIB **原版点阵**（低清像素，160×96 逻辑）：
  - tile / 角色 / 怪物用 DAT.LIB 原版点阵，**整数倍最近邻放大**（锐利、复古像素 RPG 质感，无重采样糊）；
  - 放弃「AI 重制角色」，角色用原版（或后期可选做「干净整数放大 + 边缘锐化」管线，不做 SDF/AI）。
  - 可选：后续若要做高画质，走「真实矢量/高清游戏素材」而不是 SDF 伪高清（待拍板，见 §8）。

## 4. 上游 app_fmj → gbb 插件回调映射

| 实验稿 app_fmj | 新 gbb 插件 | 说明 |
|---|---|---|
| `on_enter`（初始化 datlib/字体/hd/game） | `launch()` | 资源路径用 `g->pkg_dir`（bbk-* 目录）或保留 `/sdcard/fmj`；去掉 fmj_hd_init |
| `on_exit`（停游戏+释放） | `quit()` | 释放全部 PSRAM + 缓存 |
| `render`（整屏画 fb） | `paint()` | 改走「背景缓存+角色差分」写 `g->app->fb`，申报 `g->area/want_full` |
| `on_key`（KEY1/2/3） | `key()` | KEY1→确认/取消；KEY2=内核强刷、KEY3=内核退出（恒语义不接管） |
| `on_gesture`（虚拟键区 TAP） | `input()` | 复用虚拟键命中（十字/确认/取消/退出小屋）→ FMJ_KEY_* |
| `on_tick`（无动画） | `tick()` | 返回 `GC_EV_NONE`（无 per-frame 动画） |
| `on_media_lost` | 由内核 `GC_MEDIA_LOST → quit` | — |
| 物理三键语义 | 与 GameCore 恒语义对齐 | 左=取消/确认 需与内核确认（见 §8 决策点） |

## 5. 资源与打包

- 资源直挂（GameCore §4.2 规范）：`/sdcard/games/bbk-<name>/` 或保留实验稿 `/sdcard/fmj/`（目录直挂，`DAT.LIB` 557KB / `HZK16` 267KB / `ASC16` 4KB；**不再需要 FMJHD.BIN 40.8MB**）。
- 走 `tools/game_pkg.py bbk <dir>`（现有工具，校验就绪态）。
- 存档：复用 `fmj_game_save`（NVS blob），但命名空间 `fmj` → `te_fmj` 避免与既有固件命名冲突；仍兼容「读档入口在标题菜单」。

## 5. 工程步骤（阶段）

- **M1 引擎迁入**：把 FMJ 逻辑层（除 present/hd/screen）×迁入 `main/apps/plugins/bbk/`，CMake 登记；`gbbk.c` 骨架接 `launch/quit/paint/tick` 占位跑通（先整游戏区输出，验证资源可加载）。
- **M2 输出层改造**：`fmj_present` 改为差分申报；原版点阵整数放大渲染；背景缓存 + 角色叠加；接 `g->area/want_full`。
- **M3 素材回归原版**：去 FMJHD、去 AI 角色；title/地图 tile/战斗全原版 DAT.LIB 点阵；可选清晰化管线（整数放大 + 锐化）。
- **M4 入口 + 存档**：`app_apps.c` k_entries 加「步步高游戏」tile + 图标；存档 namespace 改 `te_fmj`。
- **M5 构建 + 真机验收**：角色走动差分（不闪/不糊）、战斗、剧情、存档、退出/重入、media_lost。
- **M6 发布准备**：游戏包资源归档（DAT 等 + 点阵放大包）、changelog、版本号。

## 6. 待拍板决策点（需用户确认）

1. **素材路线**：主推**原版点阵（复古像素清晰风，零重绘成本）**；是否仍要"高清档"？（高清档需另做干净素材管线，成本高，建议二期）
2. **存档载体**：沿用 **NVS 独立槽位（te_fmj）**（简单、已实现），还是改 GameCore 惯例「存包目录文件」？
3. **资源目录**：`/sdcard/games/bbk-fmj/`（GameCore 规范，入口列表统一）还是根目录 `/sdcard/fmj/`（实验稿沿用）？
4. **物理键**：左键=取消/右键=确认（实验稿）——与 GameCore 其他插件（左键=确认）冲突，是否统一「左键=确认/右键=取消/触摸=方向」？
5. **帧率/动画**：行走 4 帧确认存在（`k_walk_step 0,1,2,1`，原版一步一帧）→ 差分矩形内换帧零负担，维持原版节奏即可，无需降帧。
6. **镜头策略**（本次新增，见 §3.1）：A 原版事件跳屏（推荐）/ B 出界自动跳屏 / C 边缘逐步滚动（否决）。

## 7. 风险 / 注意

- **差分刷新正确性**：背景缓存 + 角色差分是本次核心改造，需防「缓存未刷新/区域申报错」的残影——真机回归重点。
- **PSRAM 预算**：背景缓存（地图 tile 全缓存可能几百 KB~几 MB）+ 角色素材，需在 8MB 内留足余量。
- **版权**：DAT.LIB 原版剧情/素材版权归原方，个人学习研究用途（同实验稿声明）。
- **坐标**：take-easy 插件统一竖屏 684×1216 逻辑坐标；FMJ 横屏（1216×684）由新输出层 `fmj_blit` 负责旋转，与 GameCore 协调（插件画 fb 不关心物理横竖，可兼容）。

## 9. 验收清单（M5 真机）

1. 人物地图走动：无全屏闪、无残影、差分区域正确（旧格清/新格画/背景不动）；
2. 战斗：血条/对话框差分，无整屏闪；
3. 剧情对话翻页：只刷对话框区；
4. 原版点阵观感：锐利、无 SDF 发灰发糊；
5. 存档：标题「继续前缘」读档正确；退出/重入不崩；media 拔卡→引导页不崩；
6. 切换其他游戏（text/novel/quiz）互斥内存不涨；
7. 无 FMJHD.BIN 且无高清库，包可玩（原版点阵）。
